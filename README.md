
Projeto desenvolvido para praticar conceitos básicos de React com Vite.

 📚 Conceitos praticados

- React + Vite
- Componentes
- JSX
- Props
- Destructuring
- useState
- Eventos com onClick
- Importação de imagens
- CSS
- Organização de componentes

🧩 Componentes
 Loja
Componente criado utilizando Props para receber:
- Nome
- Endereço
- Cidade
- Telefone

Pet
Componente criado utilizando Destructuring para receber:
- ID
- Nome
- Raça
- Cor
- Porte
- Imagem

 Contato
Componente criado utilizando Destructuring e useState para:
- Exibir informações do contato
- Permitir avaliação do atendimento de 1 a 5 estrelas

🚀 Tecnologias

- React
- Vite
- JavaScript
- CSS

 🎯 Objetivo

Projeto desenvolvido como exercício de aprendizado para praticar os fundamentos do React e compreender melhor a criação e organização de componentes.
